01 // ¿QUÉ ESTÁS APRENDIENDO?

Shodan permite buscar información observada de servicios y dispositivos conectados a Internet. En ciberdefensa lo usamos para estudiar superficie de exposición: qué servicios, tecnologías y metadatos pueden ser visibles.

filter:valor

Ejemplo: country:PY significa “filtra resultados asociados a Paraguay”.

02 // FILTROS COMUNES

country:

País.

country:PY
city:

Ciudad.

city:Asuncion
port:

Puerto.

port:443
org:

Organización asociada.

org:"Google"
isp:

Proveedor de Internet.

isp:"Tigo"
asn:

Sistema autónomo.

asn:AS15169
net:

Red o rango CIDR.

net:8.8.8.0/24
product:

Producto/servicio identificado.

product:nginx
version:

Versión observada.

version:1.18.0
os:

Sistema operativo observado.

os:"Windows Server"
hostname:

Nombre de host.

hostname:example.com
has_ssl:

Información SSL/TLS disponible.

has_ssl:true
has_screenshot:

Resultado con captura disponible.

has_screenshot:true
vuln:

Vulnerabilidad identificada por Shodan.

vuln:CVE-XXXX

03 // GLOSARIO

IP

Dirección de un equipo.

PUERTO

Punto lógico de comunicación de un servicio.

BANNER

Metadatos observados de un servicio, como producto o versión.

QUERY

Consulta completa que escribimos.

FILTER

Regla que limita los resultados.

EXPOSICIÓN

Servicio observable desde Internet. No significa automáticamente vulnerable.
