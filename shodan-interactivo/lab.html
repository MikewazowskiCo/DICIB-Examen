03 // FILTROS: APRENDE CON EJEMPLOS

country:

Filtra por país.

country:PY
port:

Filtra por puerto.

port:443
product:

Busca un producto/servicio observado.

product:nginx
has_ssl:

Indica presencia de SSL/TLS según el dato indexado.

has_ssl:true
has_screenshot:

Encuentra resultados con captura disponible.

has_screenshot:true
hostname:

Busca por nombre de host observado.

hostname:ejemplo.com

04 // GLOSARIO DE SUPERVIVENCIA

BANNER

Respuesta/metadatos observados de un servicio. No es una contraseña.

PORT

Puerto lógico donde un servicio puede estar escuchando.

FILTER

Regla que reduce los resultados de una búsqueda.

QUERY

La consulta completa que escribes para buscar.

OSINT

Inteligencia obtenida de fuentes abiertas.

SSL/TLS

Protocolos usados para proteger comunicaciones.

EXPOSURE

Servicio o dispositivo observable desde Internet. Expuesto no significa automáticamente vulnerable.

CTF

Ejercicio práctico con objetivos y evidencias controladas.

09 // REGLAS DEL ANALISTA

  • Trabaja solo con activos propios, autorizados o datos de demostración.
  • Un banner es información observada, no autorización.
  • “Expuesto” y “vulnerable” no significan lo mismo.
  • Antes de interactuar con un sistema, verifica el alcance.
  • En clase: primero entender → después buscar → luego interpretar.
